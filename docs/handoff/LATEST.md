#### 最重要: PR #34（介護版カテゴリ絞り込みの根本的再設計）

decision-maker から「タグはユーザーに画面遷移させるべきではなく、同じ画面内でフィルター
すべき」との明確な却下を受け、PR #32の「別ページ遷移リンク」方式を全面破棄。

- チップの実体は`<input type="radio">`+`<label>`。**絞り込み自体はCSSの`:has()`セレクタで
  行い、JSは件数の動的更新・0件チップ無効化・URL同期・ライブリージョン通知のみを担う強化層**
  （JS完全無効環境でも同一画面内フィルタが動作することをPlaywrightで実証済み）
- 当初は`<a href>`をJSが奪う方式（JS無効時は画面遷移にフォールバック）だったが、Planエージェント
  のセカンドオピニオンで「JS無効時のフォールバックが decision-maker の拒否した挙動そのもの」
  と指摘され、実装済みコードを`:has()`方式へ全面書き換えた
- レビュー4段階（codex review medium→strict-config high、evaluator、pr-review-toolkitセカンド
  オピニオン）で計4件のfindings（URLパラメータ保持漏れ・JS無効時空状態表示漏れ・ロジック重複・
  未使用import）を検出・修正
- 設計判断の詳細・破棄した代替案・トレードオフはADR（PR #39）に記録済み

### 同根再発スキャン（§4.6）
アーカイブ月見出しのフォントサイズが本セッション内で**3回**touchされた（#33: 15→19px、
#35: 19→24px、#37: 24→21px）。各回の根本原因は「比較対象の見落とし」（#33→#35は子要素との
差が小さすぎた/#35→#37はh1と衝突していることを見落とした）。#37時点でh1・月見出し・子要素の
3点全てを実機スクリーンショットで比較し検証済みのため**収束したと判断**（保留にはしない）。
教訓: 3階層のフォントサイズ調整は隣接1要素だけでなく上下双方の階層と比較してから確定させる
こと。他に同根候補となる再発パターンは無し。
