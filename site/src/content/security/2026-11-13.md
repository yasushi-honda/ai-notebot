## 相次ぐ大規模不正アクセスと個人情報流出

日本商工会議所は、<strong>商工会議所ネット試験管理システム</strong>が不正アクセスを受け、最大約98万人分の受験者に関する個人情報が流出した可能性があることを明らかにした[^s-1e3ce2616b]。氏名や生年月日などが対象に含まれており、個人情報保護委員会へ報告している[^s-1e3ce2616b]。

また、株式会社NTTデータは、受託している<strong>住友生命Vitality体験版・企業型</strong>などの申し込みサービスにおいて第三者からの不正アクセスを確認し、約8万名の個人情報が漏えいしたと発表した[^s-32174b128f]。同社では、サービスの早期再開に向けて必要なセキュリティ対策を進めている[^s-32174b128f]。

アララ株式会社が提供するメール配信サービス<strong>アララメッセージ</strong>においても不正アクセスが発生し、重複を除いた合計81,329,467件のメールアドレスなどが外部に持ち出された[^s-4bbf6f10f3]。同サービスは停止されており、再開時期は未定となっている[^s-7267689c4c]。

## 主要ソフトウェアとプラットフォームの深刻な脆弱性

<strong>Apache HTTP Server 2.4</strong>系において複数の脆弱性に対応した <strong>Apache HTTP Server 2.4.71</strong> が公開されました[^s-457fdf1ae1]。HTTP/2モジュールには、認証されていない攻撃者によりリモートコード実行（RCE）に悪用されるおそれのある深刻な脆弱性が存在します[^s-86013c2901]。

NoSQLデータベースの <strong>MongoDB Server</strong> にはレプリケーション処理に関する「Use After Free」の脆弱性「CVE-2026-118383」が確認されており、任意のコード実行やサービス拒否に陥るおそれがあります[^s-d189c201f5]。Googleはブラウザ <strong>Chrome</strong> のセキュリティアップデートを公開し、83件の脆弱性に対処しました[^s-2fe7e0a98e]。

アドバイザリ公表時点で <strong>MongoDB Server</strong> の脆弱性悪用は確認されていません[^s-d189c201f5]。一方 <strong>Chrome</strong> では、2日前に公開されたアップデートに含まれる「CVE-2026-125350」ですでに悪用が確認されていました[^s-2fe7e0a98e]。

## ゼロデイ脆弱性の悪用と権限昇格攻撃の急増

N-ableの <strong>N-central</strong> に存在する <strong>4EverAble2Shell</strong> というゼロデイ脆弱性が、概念実証コードが公開されてから数時間後には悪用されていることが確認された[^s-4ab159d0ea]。研究者によると、この攻撃によってサーバーが侵害され、暗号資産マイニングツールが展開されており、最新のセキュリティ更新プログラムを適用していた19システムを含む少なくとも21システムが影響を受けている[^s-4ab159d0ea]。また、セキュリティ研究者であるAbdelhamid Naceri氏によって、Windowsの共通ログファイルシステムドライバーを標的とした <strong>SignDrop</strong> という新しいゼロデイ脆弱性の実証コードが公開された[^s-1acaa8e77a][^s-1fe252b0a6]。この脆弱性を利用すると、通常のローカルユーザーが <strong>SYSTEM</strong> 権限を取得できるおそれがある[^s-1acaa8e77a]。さらに、ConnectWise ScreenConnectの導入環境を狙う継続中の攻撃キャンペーンでは、修正済みの重要セキュリティ不具合である <strong>CVE-2026-84869</strong> が悪用されていることが判明している[^s-daa356fef1]。

## 巧妙化する偽警告・サポート詐欺と偽アプリ誘導

福島県田村市は、2026年10月24日に幼児保育施設の職員がインターネット利用中にサポート詐欺の被害に遭い、パソコン内の個人情報が流出した可能性があると明らかにしました[^s-591a341045]。表示されたマルウェア感染の偽警告に従ってサポート詐欺サイトへアクセスし、遠隔操作ソフトをダウンロードしたことで、保育活動中の写真やアンケート記載の氏名などが流出したおそれがあります[^s-591a341045]。

また、警察庁は2026年11月11日に公式Xで、警察庁推奨アプリのダウンロードページを装った偽サイトについて注意を呼びかけました[^s-36392885b5]。警察庁をかたるSMSで偽のウェブサイトへ誘導し、不審なファイルをダウンロードさせる手口が確認されています[^s-36392885b5]。さらに、人工知能ツールを装った類似ドメインが、ブラウザを乗っ取るマルウェアや検索を乗っ取る拡張機能などへユーザーを誘導していることもセキュリティ研究者によって発見されています[^s-50b7d482cf]。

## 今日の用語

- <strong>不正アクセス</strong>（ふせいあくせす）：他人のIDやパスワードを使ったり、システムの弱点を突いたりして、権限なく侵入すること[^s-1e3ce2616b][^s-32174b128f]。
- <strong>脆弱性</strong>（ぜいじゃくせい）：ソフトウェアや機器の設計・実装・設定・運用などにある、攻撃に悪用されうる弱点のこと[^s-457fdf1ae1][^s-86013c2901]。
- <strong>リモートコード実行</strong>（りもーとこーどじっこう）：離れた場所から、狙った機器に任意のプログラムを実行させられてしまうこと[^s-86013c2901]。
- <strong>セキュリティパッチ</strong>（せきゅりてぃぱっち）：脆弱性を修正するために提供される更新プログラムのこと[^s-2fe7e0a98e]。
- <strong>ゼロデイ</strong>（ぜろでい）：開発元にまだ知られていないなどの理由で修正が用意されていない脆弱性、またはそれを悪用する攻撃のこと[^s-4ab159d0ea][^s-1acaa8e77a]。
- <strong>CVE</strong>（しーぶいいー）：脆弱性を共通の番号で識別・共有するために、CVEプログラムで割り当てられる識別番号のこと[^s-daa356fef1]。
- <strong>マルウェア</strong>（まるうぇあ）：利用者の機器に被害を与える目的で作られた不正なプログラムの総称[^s-591a341045][^s-50b7d482cf]。
