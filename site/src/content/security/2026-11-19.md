## Java4Shell脆弱性の公開と緊急パッチ適用

2026年11月17日、<strong>OpenJDK</strong>はJavaの実行環境である<strong>HotSpot</strong>におけるBase64デコード処理の脆弱性（<strong>CVE-2026-114938</strong>、通称<strong>Java4Shell</strong>）の修正と関連情報を公開しました[^s-9a64950a8c]。この脆弱性は、x86-64向けのAVX-512 VBMI組み込み実装におけるヒープバッファオーバーフローに起因しています[^s-9a64950a8c][^s-88c7102cce]。

セキュリティ研究組織の<strong>Calif</strong>は、<strong>Keycloak</strong>、<strong>Atlassian Jira</strong>、<strong>Atlassian Confluence</strong>、<strong>Jenkins</strong>などの複数のJava製アプリケーションにおいて、認証なしでのリモートコード実行が可能であると報告しています[^s-223101d573][^s-fa3db108e0]。細工されたデータを入力されることで、機微な情報の窃取や任意のコード実行につながるおそれがあります[^s-88c7102cce][^s-fa3db108e0]。

JPCERT/CCは2026年11月18日時点で実際の攻撃への悪用は確認していないものの、影響を受ける環境を確認し速やかに対策を実施するよう呼びかけています[^s-fa3db108e0]。また、<strong>Oracle</strong>や<strong>OpenJDK</strong>はそれぞれセキュリティ情報や更新プログラムを公開しています[^s-fa3db108e0]。

### すぐできる対策

- 影響を受けるJava実行環境を使用している場合、Java実行環境を使用している方は、使用しているJavaディストリビューションの開発元が提供する情報を確認し、本脆弱性が修正されたバージョンへの更新を速やかに実施してください[^s-fa3db108e0]。
- Java実行環境を同梱する製品やアプリケーションを使用している場合、Java実行環境を同梱する製品やアプリケーションを使用している方は、製品の開発元が提供する情報を確認し、必要な対策を実施してください[^s-fa3db108e0]。

## 国内企業を襲う不正アクセスと情報漏えい

<strong>楽天証券</strong>はシステムが侵害され、顧客の個人情報が流出した可能性があることを明らかにしました[^s-1a3bc91bb4][^s-a11a730646]。退会者を含む会員の最大約<strong>447万口座</strong>に関する氏名や住所、年収などの情報が含まれており、パスワードや暗証番号の流出は確認されていません[^s-1a3bc91bb4][^s-a11a730646]。

理化学研究所は、スーパーコンピュータ<strong>富岳</strong>の運用系システムが不正アクセスを受けたと発表しました[^s-f6f1c1e5a4]。インターネット上のダッシュボードを足がかりに内部ネットワークへ侵入され、利用者の認証情報などが流出した可能性があり、攻撃者は一部の認証情報を使用して他システムへの接続も試みていました[^s-f6f1c1e5a4]。

日本郵便は、法人顧客向けサイト<strong>JP Business Tool Box</strong>で送り状ラベルの発注元情報を別の顧客が閲覧できる不具合が生じたと明らかにしました[^s-5fa7a1b7cb]。最大4807件の情報が閲覧された可能性があり、対象顧客には書面で個別に連絡しています[^s-5fa7a1b7cb]。

### すぐできる対策

- システムへの不正アクセス等により個人情報流出の可能性がある場合、楽天証券の対象となる顧客は、同社や関係者を装った連絡などに注意してください[^s-1a3bc91bb4]。

## NGINX等に浮上した深刻なリモートコード実行の脅威

国家サイバー統括室は2026年11月19日、Webサーバーの <strong>nginx</strong> にリモートから未認証で任意のコード実行等が可能となる脆弱性が公表されたとして、対象環境の運用管理者に速やかなアップデートの適用等を求める注意喚起を行いました[^s-b174a57253]。

nginx.orgとF5は2026年11月18日、<strong>NGINX</strong> のHTTP/2の実装における脆弱性2件を公表し、<strong>nginx 1.30.7</strong> と <strong>1.31.9</strong> のリリースでこの2件を含む計10件の脆弱性を同時に修正しました[^s-b174a57253]。確認された2件のうち、<strong>CVE-2026-123007</strong> はオープンソースコードに導入されてから10年が経過している欠陥であり[^s-fb8b318a04]、認証不要でネットワークから細工した通信を送ることでworkerプロセスのクラッシュを引き起こすおそれがあります[^s-b174a57253]。

### すぐできる対策

- 対象環境の運用管理者は、速やかなアップデートを適用してください[^s-b174a57253]。

## Oracleの11月定期パッチとChromeの大量修正

Oracleは2026年11月17日に、四半期ごとのセキュリティ更新を補完する累積セキュリティ更新のCritical Security Patch Updateを公開し、のべ655件の修正パッチを提供しました[^s-d013c95bd9]。対象製品にはOracle Database ServerやOracle Java SEなどが含まれ、CVSSv3.1のベーススコアで7.0以上とされる脆弱性が311件確認されています[^s-d013c95bd9]。

Googleは現地時間2026年11月17日にウェブブラウザのGoogle Chrome 158を公開し、あわせて204件の脆弱性に対応しました[^s-684751e8fc]。このうち重要度がもっとも高いクリティカルとされる脆弱性が6件含まれており、Windows、macOS、Linux向けに順次展開されます[^s-684751e8fc]。

### すぐできる対策

- Windows、macOS、Linuxを利用している場合、Google Chromeの利用者は、提供されるアップデートを適用してください[^s-684751e8fc]。

## 今日の用語

- <strong>脆弱性</strong>（ぜいじゃくせい）：ソフトウェアや機器の設計・実装・設定・運用などにある、攻撃に悪用されうる弱点のこと[^s-9a64950a8c][^s-88c7102cce]。
- <strong>リモートコード実行</strong>（りもーとこーどじっこう）：離れた場所から、狙った機器に任意のプログラムを実行させられてしまうこと[^s-223101d573][^s-fa3db108e0]。
- <strong>CVE</strong>（しーぶいいー）：脆弱性を共通の番号で識別・共有するために、CVEプログラムで割り当てられる識別番号のこと[^s-9a64950a8c]。
- <strong>不正アクセス</strong>（ふせいあくせす）：他人のIDやパスワードを使ったり、システムの弱点を突いたりして、権限なく侵入すること[^s-f6f1c1e5a4]。
- <strong>認証情報</strong>（にんしょうじょうほう）：IDやパスワードなど、本人であることを確かめるための情報のこと[^s-f6f1c1e5a4]。
- <strong>セキュリティパッチ</strong>（せきゅりてぃぱっち）：脆弱性を修正するために提供される更新プログラムのこと[^s-d013c95bd9]。
